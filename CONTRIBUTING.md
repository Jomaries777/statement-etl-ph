# Contributing

Thanks for helping. Two rules matter more than any other:

1. **Never share a real statement.** Not as an attachment, a screenshot, a pasted table, or a test fixture. The same goes for real reference numbers, account or mobile numbers, card digits, names and PDF passwords. Every test statement in this repository is synthetic, and must stay that way.
2. **Every statement must reconcile.** A parser change is done when the rows it reads add up to the totals the statement prints, for every fixture.

## Development

```bash
python -m venv .venv
.venv/bin/pip install -e '.[dev,gmail]'
.venv/bin/pytest
```

The synthetic PDFs in `tests/fixtures/` are generated by the `make_*_fixture.py` scripts next to them, and rebuilt automatically when missing.

## Reporting a statement that won't parse

Use the [parse problem](.github/ISSUE_TEMPLATE/parse-bug.yml) issue form. It asks for the `-v` output and a description of the layout with invented values, which is everything needed to reproduce it with a synthetic statement.
